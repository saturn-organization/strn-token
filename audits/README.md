# External audit reports

No completed independent STRN audit report is published here yet.

This directory is reserved for completed external reports authorized for publication. For each report, record the auditor, report date, reviewed source commit, scope/exclusions, remediation commit and unresolved or accepted findings. A report applies to its stated scope and revisions, not automatically to subsequent changes on `main`.

See [proposed audit scope](../docs/AUDIT_SCOPE.md) and [verification and evidence packaging](../docs/VERIFICATION.md). Internal test logs and analyzer output are not independent audit reports.
